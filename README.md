# CardioVision AI

AI-assisted cardiovascular risk screening from retinal fundus images using deep learning, multimodal learning, and explainable AI.

## Objective

CardioVision AI investigates whether retinal fundus photographs can provide useful information for estimating cardiovascular risk.

## Planned Architecture

Retinal Fundus Image
        ↓
Image Quality Assessment
        ↓
Retinal Vision Model
        ↓
Retinal Vessel Analysis
        ↓
Clinical Metadata
        ↓
Multimodal Fusion
        ↓
Cardiovascular Risk Prediction
        ↓
Explainability + Confidence
        ↓
Clinical-style Dashboard

## Advanced Features

- Retinal image quality assessment
- Retinal vessel segmentation
- Vessel feature extraction
- Deep learning
- Transfer learning
- Multimodal learning
- Cardiovascular risk prediction
- Grad-CAM explanations
- SHAP explanations
- Uncertainty estimation
- Out-of-distribution detection
